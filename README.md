## 📖 About

This repository contains solutions to Java programming questions that I solve while learning the language. Each question is saved as a separate file (`Question1.java`, `Question2.java`, ...) so that every program is easy to find, compile, and run independently.

## 🛠️ Prerequisites

- **JDK 8 or higher** ([Download](https://www.oracle.com/java/technologies/downloads/))
- A terminal or any IDE (IntelliJ IDEA, VS Code, Eclipse, etc.)

Verify your installation:

```bash
java -version
javac -version
```

## 📂 Repository Structure

```
Java/
├── Question1.java
├── Question2.java
├── ...
└── README.md
```

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone https://github.com/riyajul-saha/Java.git
cd Java/code/

# 2. Compile a program
javac Question1.java

# 3. Run it (with command line arguments, if required)
java Question1 arg1 arg2 arg3
```
